01Goal

This was a simple final project for my school electronics class.

02How I built it

Using what I learned about 3D modeling from my past projects, I spent some time gathering measurements before asking my teacher to print it. I had to scale the project down a bit to make it one single print, which made it cleaner, but everything still fit in the end.

03The hard part

The main issue was soldering in such a small space. The speakers were designed so the wires could only be soldered on once the speaker was already inside. It took some precision soldering, but I got it done in the end.

04Parts

This was a school project, so I couldn't track down the exact model numbers for the driver and amp.

05Looking back

Next time I'd design the enclosure with a removable back panel, so I could solder the driver outside the box and slide it in afterward.
