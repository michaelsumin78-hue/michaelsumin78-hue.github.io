01The problem

This year I was tasked with fixing my school's CNC machine. It broke after a student misused it and the machine dug into itself. Since then it ignored its machine limits and pushed itself along the Y axis farther than it can go.

02Finding the fault

The machine is an i2R8, so I took some time to research it first. Then I set up the UCCNC control software on my laptop so I could figure out what the software wasn't seeing.

With UCCNC running, I worked out how the machine actually functions. Each axis has a limit sensor, and a metal bracket on the moving part passes in front of it. When the sensor detects the bracket, the machine stops before it can go any farther.

The X and Z sensors were working properly, but the Y sensor wasn't. After some troubleshooting I found that the Y-axis sensor was completely dead, so nothing told the machine to stop.

03Next

I'm currently working on a new sensor to replace the old one.
