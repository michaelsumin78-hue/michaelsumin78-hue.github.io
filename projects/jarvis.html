01Goal

This started as an ESP32 hardware prototype. I rebuilt it as software so it could do real work on my computer instead of only answering questions.

02How it works

  • Listening. A Porcupine wake word (“Hey Jarvis”) or a push-to-talk key starts recording. Whisper turns the audio into text.
  • Thinking. A language model with tool calling decides what to do: open apps and URLs, search the web, control volume and media, manage files, play songs on Spotify, look at the screen, or run a longer research task.
  • Speaking. ElevenLabs reads the answer back. A tray icon changes color for idle, listening, thinking and speaking.
  • Dashboard. A desktop window shows the conversation log, research reports and screen-view history, and starts the assistant if it is not running.

03Design decisions

Confirmation before destructive actions

Shutdown, restart and delete ask for spoken confirmation before they run. A misheard command should never cost a file.

One source of truth for start and stop

The desktop shortcut and the dashboard both start and stop the assistant. I pulled that logic into a single module so the two entry points cannot drift apart.

Single-key push-to-talk

Key combos flickered because of how Windows auto-repeats modifier keys, which cut recordings short. A single key fixed it, and the README explains why.

04Results

It runs from the system tray on my PC every day. The codebase has over 300 automated tests, and tests never call the paid speech or language APIs.
