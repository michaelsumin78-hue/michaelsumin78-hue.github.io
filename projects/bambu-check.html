01Goal

I kept losing prints to the same problems: unsupported overhangs, thin walls, long bridges, and settings that do not suit the part. I wanted a tool that catches them before the printer does.

02How it works

  • Analysis. It reads a Bambu Studio project or a raw mesh or STEP file, then flags overhang faces, thin walls, risky bridge spans and known-bad settings.
  • Orientation. It scores rotations and suggests a better one. Each part gets a category (structural, aesthetic or mixed) with the reasons for its guess, and changing the category re-scores the part.
  • Plate. It packs parts on the bed, recommends settings, and exports a .3mf that opens straight in Bambu Studio.
  • Two front ends, one library. An interactive 3D desktop app and the original command-line tool that writes an HTML report.

03Design decisions

View from below

The 3D view looks at each part from slightly below the horizon. Overhang faces point down, so the usual view from above hides every face worth looking at.

Verify the file, not the screen

Bambu Studio throws away a whole project over one unknown value without an error. I check every exported file with Bambu Studio's own headless command-line mode instead of trusting that it looks right.

04Results

Packaged as a Windows app I pinned to my taskbar and use before every print. Over 240 automated tests cover the analysis.
