01Goal

Find local businesses that would benefit from a website, and make the first conversation with them easier.

02How it works

  • Search. Type a neighborhood. OpenStreetMap services geocode it and list the businesses inside, with no API keys required.
  • Scoring. Each business is ranked by how likely it is to want a site and how easy it is to contact.
  • Verification. OpenStreetMap often lacks a website tag even when a site exists, so the app can confirm against Google Places and separates “checked, none” from “unknown.”
  • Outreach. Each lead gets a sample website preview and a short call script.

03Design decisions

Respecting usage policies

Nominatim's policy forbids search-as-you-type, so the autocomplete box uses a separate service built for it. I declined to scrape Google Maps and used the official Places API instead.

No made-up data

When a business's owner is not in the data, the call script asks for the name instead of guessing one.
