01Goal

Generate complete short-form videos from a single theme, with every stage after the story running locally and free.

02How it works

  • Story. The Claude API writes an original first-person story from a theme or a one-line premise.
  • Narration. Kokoro text-to-speech reads it aloud on my machine.
  • Captions. faster-whisper finds the timing of every word, which drives burned-in, word-by-word captions.
  • Assembly. ffmpeg composites narration, captions and a generated background at 1080x1920.

Each stage talks to the next through files and small data classes, so I can rerun or swap one stage without touching the rest.

03What testing against the real thing caught

Stubs hide real failures

Unit tests passed against fakes, but the first live run failed: the code sent a sampling parameter that current models reject. Live runs also showed captions stranding single words because my gap threshold was shorter than the narrator's real comma pauses.

Tests that cannot spend money

After one test made a real API call, I added a fixture that swaps every key for a dummy value during tests.

04Results

Generates finished videos end to end for about $0.004 each, around $0.40 per hundred. Only the story stage costs anything. It ships as a Windows desktop app.
